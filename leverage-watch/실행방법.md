# 실행 방법

내 컴퓨터에서 돌릴 때의 안내입니다. 서버에 올릴 거면 `서버설치.md` 를 보세요.

처음 한 번만 30분 정도 걸리고, 그 다음부터는 켜두기만 하면 됩니다.

---

## 0단계 · 파이썬 설치 (이미 있으면 건너뛰기)

터미널에서 확인:

```
python3 --version
```

**Windows**: 터미널은 시작 → `cmd` 또는 `PowerShell`. 명령어는 `python3` 대신 **`python`** 을 쓰세요.
**Mac**: Spotlight(⌘+Space) → `터미널`.

`3.10` 이상이면 됩니다. 없거나 낮으면 [python.org/downloads](https://www.python.org/downloads/) 에서 설치하세요.

> **Windows 설치 시 주의**: 설치 첫 화면의 **"Add python.exe to PATH"** 를 반드시 체크하세요. 안 하면 터미널에서 `python` 명령을 못 찾습니다.

---

## 1단계 · 압축 풀고 폴더로 이동

`leverage-watch.zip` 을 원하는 곳에 풀어주세요. 바탕화면이라면:

**Windows**
```
cd %USERPROFILE%\Desktop\leverage-watch
```

**Mac**
```
cd ~/Desktop/leverage-watch
```

`dir`(Windows) 또는 `ls`(Mac) 를 쳐서 `run.py`, `config.yaml` 이 보이면 제대로 온 겁니다.

---

## 2단계 · 필요한 패키지 설치

```
pip install -r requirements.txt
```

1~2분 걸립니다. 에러가 나면 `pip3`, 또는 `python -m pip install -r requirements.txt` 를 써보세요.

---

## 3단계 · 규칙이 제대로 도는지 확인

```
python3 selftest.py
```

인터넷 없이도 도는 검사입니다. **`12/12 통과`** 가 나와야 합니다. 여기서 실패하면 다음으로 넘어가지 마세요.

---

## 4단계 · 티커 전수 확인 (처음 한 번)

```
python3 run.py --audit
```

설정에 적힌 152종이 실제로 데이터를 주는지 확인합니다. **5~10분 걸립니다.** 미국 레버리지 ETF는 상장폐지·티커변경이 잦아서 몇 개는 실패하는 게 정상입니다.

"데이터 없음" 목록이 나오면 `config.yaml` 에서 해당 줄을 지우세요. 안 지워도 그 종목만 '보류'로 표시될 뿐 나머지는 정상입니다.

---

## 5단계 · 첫 점검 실행

```
python3 run.py
```

이렇게 나오면 성공입니다:

```
기초자산 61건 수집 …
진입 0 · 이탈 0 · 보유 0 · 관심 3 · 관망 51 · 상품없음 5 · 보류 0
새 알림 없음.
```

**진입 0이 정상입니다.** 조건이 다 맞는 날에만 숫자가 올라갑니다.

`받지 못함 61건` 처럼 대부분 실패하면 인터넷이나 방화벽 문제입니다. 회사 네트워크면 개인 네트워크에서 다시 시도해 보세요.

---

## 6단계 · 대시보드 띄우기

```
python3 server.py
```

브라우저에서 **http://127.0.0.1:8777** 로 접속하세요. 이 터미널 창은 켜둔 채로 둡니다. 끄면 대시보드도 꺼집니다.

설정한 시각(한국장 15:45, 미국장 06:10)에 자동으로 점검하고 신호가 나면 알립니다.

---

## 7단계 · 텔레그램 알림 연결

여기까지는 대시보드만 보이고 휴대폰 알림은 아직 안 옵니다.

1. 텔레그램에서 **@BotFather** 검색 → `/newbot` → 이름 정하면 **토큰**을 줍니다 (`1234567:AAxxx...`)
2. 방금 만든 봇을 검색해서 **아무 메시지나 한 번 보내세요.** 이걸 안 하면 봇이 먼저 말을 걸 수 없습니다. 여기서 막히는 경우가 제일 많습니다.
3. **chat id 찾기** — `config.yaml` 에 토큰만 먼저 넣고 아래를 실행하면 번호를 찾아줍니다.

```
python3 run.py --chatid
```

   (수동으로 하려면 텔레그램에서 **@userinfobot** 을 검색해 아무 말이나 보내도 됩니다)
4. `config.yaml` 을 메모장으로 열어서 위쪽을 고칩니다:

```yaml
alerts:
  channel: telegram
  telegram:
    bot_token: "1234567:AAxxxxxxxxxxxxxxx"
    chat_id: "987654321"
```

5. 연결 확인:

```
python3 run.py --test
```

휴대폰에 메시지가 오면 끝입니다. 서버를 다시 시작하세요 (`Ctrl+C` 로 끄고 `python3 server.py`).

## 8단계 · 임계값 맞추기 (권장)

```
python3 run.py --calibrate
```

직진성 기준값(`er_min 0.15` / `r2_min 0.45`)은 인공 데이터로 정한 값이라 실제 시장과 안 맞을 수 있습니다. 이 명령이 지금 실제 분포를 보여줍니다.

- **"둘 다 0/59"** → 기준이 너무 빡빡합니다. `config.yaml` 의 `er_min` / `r2_min` 을 낮추세요
- **절반 넘게 통과** → 너무 헐겁습니다. 올리세요
- **전체의 10~20%** 통과가 적당합니다

---

## 계속 돌리기

`server.py` 는 컴퓨터가 켜져 있어야 동작합니다. 노트북을 매일 닫는다면:

**방법 A** — 못 켠 날은 다음에 켜고 `python3 run.py` 를 한 번 수동으로 돌리세요. 상태는 파일에 저장되므로 며칠 건너뛰어도 이어집니다.

**방법 B** — 상시 켜진 PC나 라즈베리파이가 있으면 거기에 두세요. 설정은 `서버설치.md` 에 있습니다.

## 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| `python3: command not found` | Windows면 `python` 으로. 그래도 안 되면 파이썬 재설치 시 PATH 체크 |
| `No module named 'yfinance'` | 2단계 누락이거나 다른 파이썬에 설치됨. `python3 -m pip install -r requirements.txt` |
| `받지 못함 61건` | 인터넷/방화벽. 회사망이면 개인망에서 시도 |
| 국내 종목만 안 들어옴 | `pip install pykrx` 후 다시 실행 |
| 대시보드가 안 열림 | `server.py` 터미널이 켜져 있는지 확인. 포트 충돌이면 `--port 9000` |
| 텔레그램 안 옴 | 봇에게 먼저 말을 걸었는지 확인 후 `run.py --test` |
| 신호가 한 번도 안 뜸 | 정상입니다. 8단계로 실제 분포 확인 후 판단하세요 |
