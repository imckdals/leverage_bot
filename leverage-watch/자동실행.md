# 컴퓨터를 꺼도 알림 받기

## 먼저: 지금 상태로는 안 됩니다

스케줄러가 `server.py` 안에 들어 있습니다. 그 터미널 창을 닫거나 컴퓨터가 꺼지면 아무것도 안 나갑니다. 특히 **미국장 마감 알림은 새벽 6시 10분**이라 사실상 못 받습니다.

## 선택지

| 방법 | 비용 | 컴퓨터 꺼도 됨 | 난이도 |
|---|---|---|---|
| 컴퓨터 켜두기 | 0원 | ✕ | 없음 |
| OS 스케줄러 (작업 스케줄러 / launchd) | 0원 | ✕ (켜져 있어야) | 중 |
| **GitHub Actions** | **0원** | **○** | **중** |
| 라즈베리파이 · 미니PC | 5~10만원 | ○ | 중 |
| 클라우드 VPS | 월 5천~1만원 | ○ | 상 |

**GitHub Actions 를 추천합니다.** 서버를 만들 필요도, 돈을 낼 필요도 없고, 컴퓨터가 꺼져 있어도 GitHub 쪽 컴퓨터에서 알아서 돕니다. 준비는 다 해뒀고 설정만 하시면 됩니다.

대시보드는 GitHub 에서 못 봅니다. 알림은 GitHub 가 보내주고, 화면을 보고 싶을 때만 내 컴퓨터에서 `python server.py` 를 켜는 식으로 쓰면 됩니다.

# GitHub Actions 설정 (20분)

## 1. GitHub 가입

[github.com](https://github.com) 에서 무료 가입.

## 2. 비공개 저장소 만들기

우측 상단 **+** → **New repository**

- Repository name: `leverage-watch`
- **Private 를 반드시 선택하세요.** Public 으로 하면 설정이 인터넷에 공개됩니다.
- **Create repository**

> 비공개 저장소는 월 2,000분까지 무료입니다. 이 도구는 한 번에 3~5분, 하루 3번, 월 300분쯤 씁니다.

## 3. 파일 올리기

만들어진 저장소 화면에서 **uploading an existing file** 링크를 누르고, 압축 푼 폴더 안의 파일을 **전부** 끌어다 놓으세요.

> **주의**: `.github` 폴더가 빠지면 자동 실행이 안 됩니다. 숨김 폴더라 안 보일 수 있습니다.
> - Windows: 탐색기 → 보기 → 숨긴 항목 체크
> - Mac: 폴더에서 `⌘ + Shift + .`

**Commit changes** 를 누르면 업로드됩니다.

## 4. 텔레그램 토큰 등록 (Secrets)

토큰을 파일에 적지 않고 GitHub 금고에 넣습니다.

### 가는 길

주소창에 이걸 바로 치는 게 제일 빠릅니다. `내아이디` 만 바꾸세요.

```
https://github.com/내아이디/leverage-watch/settings/secrets/actions
```

메뉴로 찾아가려면:

1. 내 저장소 화면에서 위쪽 탭 맨 오른쪽 **⚙ Settings**
   > **주의**: 오른쪽 위 프로필 사진을 눌러 나오는 Settings 가 아닙니다.
   > 저장소 이름 바로 아래 줄에 있는 `Code · Issues · Pull requests · Actions · … · Settings` 중 맨 오른쪽입니다.
2. 왼쪽 목록을 아래로 내려 **Security** 묶음 → **Secrets and variables** 클릭
3. 펼쳐지면 **Actions** 클릭
   > `Codespaces`, `Dependabot` 도 같이 나옵니다. 반드시 **Actions** 여야 합니다.
4. 오른쪽 위 초록 버튼 **New repository secret**

### 넣을 값 두 개

| Name | Secret |
|---|---|
| `TELEGRAM_BOT_TOKEN` | @BotFather 가 준 토큰 (`8012345678:AAH...` 형태) |
| `TELEGRAM_CHAT_ID` | 나와 봇의 대화방 번호 (`123456789`) |

`chat_id` 를 모르겠으면, `config.yaml` 에 토큰만 넣고 이 명령을 실행하세요.

```
python run.py --chatid
```

봇에게 아무 메시지나 한 번 보낸 뒤 실행하면 번호를 찾아서 알려줍니다.

하나 넣고 **Add secret** → 다시 **New repository secret** 으로 두 번째.

### 틀리기 쉬운 것

- **이름은 정확히 그대로.** 대문자, 밑줄까지 같아야 합니다. `TELEGRAM_BOT_TOKEN` 이 맞고 `Telegram_Bot_Token` 이나 `TELEGRAM-BOT-TOKEN` 은 안 됩니다. 오타가 나면 에러 없이 그냥 빈 값이 되어 알림만 안 옵니다.
- **따옴표 넣지 마세요.** `"8012345678:AAH..."` 가 아니라 `8012345678:AAH...` 입니다.
- **토큰은 콜론까지 통째로.** 앞의 숫자부터 끝까지 전부 복사하세요.
- **저장하면 다시 못 봅니다.** 값이 가려지고 수정만 됩니다. 잘못 넣었으면 Update 로 덮어쓰면 됩니다.

목록에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 두 줄이 보이면 된 겁니다.

## 5. 실행 권한 켜기

저장소 → **Settings** → **Actions** → **General** → 맨 아래 **Workflow permissions**

- **Read and write permissions** 선택 → **Save**

보유 기록(`state.json`)을 저장소에 다시 써야 해서 필요합니다. 이게 없으면 같은 신호를 매번 다시 보냅니다.

## 6. 지금 한번 돌려보기

저장소 → **Actions** 탭 → 왼쪽 **레버리지 관제** → **Run workflow** → 초록 버튼

3~5분 뒤 텔레그램에 메시지가 오면 끝입니다. 신호가 없으면 아무것도 안 올 수도 있는데, `digest` 를 켜고 돌리면 최소한 "보유 없음" 한 줄은 옵니다.

실패하거나 아무것도 안 오면 **Actions 탭 → 방금 실행 → 점검 실행** 로그를 펼쳐보세요. Secrets 가 잘못됐으면 이렇게 찍힙니다.

```
텔레그램으로 못 보냈습니다. 비어 있는 값: bot_token
GitHub Actions 에서 실행 중입니다. Secrets 를 확인하세요:
  저장소 → Settings → Secrets and variables → Actions
```

이 문구가 보이면 이름 오타이거나 Secret 이 등록되지 않은 것입니다.

## 이제 이렇게 돕니다

| 한국시간 | 무엇 |
|---|---|
| 평일 15:45 | 한국장 마감 점검 |
| 평일 06:10 | 미국장 마감 점검 |
| 평일 08:30 | 보유 종목 아침 요약 |

컴퓨터를 꺼도, 여행 중에도 옵니다.

시간을 바꾸려면 `.github/workflows/scan.yml` 의 `cron` 을 고치세요. **UTC 기준이라 한국시간에서 9시간을 빼야 합니다.** 예를 들어 한국 09:00 → `0 0 * * 1-5`.

## 알아둘 것

**시간이 정확하지 않습니다.** GitHub 의 예약 실행은 혼잡하면 5~30분 늦습니다. 장 마감 직후 딱 맞춰 사야 하는 도구가 아니라 괜찮지만, 정각을 기대하지는 마세요.

**60일 동안 저장소에 아무 변화가 없으면 예약 실행이 자동으로 꺼집니다.** 신호가 나면 `state.json` 이 커밋되므로 보통 문제없지만, 몇 달간 신호가 하나도 없으면 멈출 수 있습니다. Actions 탭에 들어가 한 번 수동 실행하면 다시 살아납니다.

**대시보드는 안 보입니다.** 화면을 보려면 내 컴퓨터에서 `python server.py` 를 켜세요. 저장소에서 `state/latest.json` 을 받아 `state/` 폴더에 넣으면 GitHub 가 점검한 최신 결과가 그대로 보입니다.

**설정을 바꾸려면** 저장소에서 `config.yaml` 을 직접 편집(연필 아이콘)하고 커밋하면 다음 실행부터 반영됩니다.

## 컴퓨터를 켜두는 쪽을 택한다면

**Mac** — 터미널에서 이렇게 켜면 잠자기를 막습니다.

```bash
caffeinate -i python3 server.py
```

**Windows** — 설정 → 시스템 → 전원 및 배터리 → 화면 및 절전 → 전부 "안 함". 노트북은 덮개를 닫으면 그래도 자므로, 제어판 → 전원 옵션 → 덮개를 닫을 때 → "아무 것도 안 함" 으로 바꾸세요.

둘 다 **컴퓨터가 켜져 있어야** 동작합니다. 새벽 6시 알림을 받으려면 밤새 켜둬야 합니다.
